# portfolio-gustavo-matos

Portfólio pessoal desenvolvido com HTML semântico e CSS, apresentando minha trajetória, objetivos, habilidades, projetos e contato.

## Site publicado

https://gustavom-julio.github.io/portfolio-gustavo-matos

## Tecnologias usadas

- HTML semântico
- CSS
- Git e GitHub (branches e Pull Requests)
- GitHub Pages (publicação do site)
- Visual Studio Code

## Estrutura do projeto

- `index.html`: página inicial (sobre mim, objetivos, habilidades e contato)
- `projetos/projetos.html`: página com meus projetos
- `css/style.css`: estilos do site
- `img/`: imagens usadas no site
